# Banque d'images de la plaquette

Dépose ici les photos générées ou prises pour la plaquette freelance.

## Nommage

`<modèle>-<lettre>.jpg`, en minuscules, sans accent ni espace :

| Fichier | Emplacement | Format |
|---|---|---|
| `t2-a.jpg`, `t2-b.jpg`, `t2-c.jpg` | Modèle 2 (Terre), image en arche | 3:4 portrait |
| `t3-a.jpg`, `t3-b.jpg`, `t3-c.jpg` | Modèle 3 (Affiche), plein cadre | 3:4 portrait |
| `t4-1.jpg` à `t4-6.jpg` (numérotées), regroupées par trois dans `PQ_PHOTOS` | Modèle 4 (Cartes), galerie : un jeu de trois | 16:10 |
| `t8-a.jpg`, `t8-b.jpg`, `t8-c.jpg` | Modèle 8 (Citation) | 4:5 portrait |
| `t10-a1.jpg` à `t10-a3.jpg`, `t10-b1.jpg` à `t10-b3.jpg` | Modèle 10 (Studio), bande : un jeu de trois | 16:9 |
| `p-a.jpg` | Portrait d'exemple du bandeau « Qui je suis » : affiché à l'écran seulement quand la personne n'a pas de photo, **jamais exporté** | 1:1 carré |

## Règles

- JPEG, 1000 à 2000 px de large, moins de 300 Ko chacun (le site est servi tel quel).
- Aucun logo, aucun texte lisible, aucune personne reconnaissable sans son accord.
- Une image générée par IA ne prouve pas une mission réelle : ne l'utilise pas comme « réalisation ».

## Les rendre disponibles dans l'application

Ajoute une ligne dans la liste `PQ_PHOTOS` de `index.html` (nom affiché, modèles concernés, fichiers). Elle apparaît ensuite sous « Photos proposées pour ce modèle », dans l'onglet Plaquette, section « Images ».
